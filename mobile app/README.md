# Sage

تطبيق تدريب معرفي يومي، عربي وإنجليزي، بيشتغل أوفلاين.
A daily cognitive-training app, Arabic and English, works offline.

## التركيب على الموبايل

**١.** ارفع الملفات التمانية دي على GitHub Pages (أو أي استضافة https):
`index.html` · `manifest.webmanifest` · `sw.js` · `icon-180.png` · `icon-192.png`
· `icon-512.png` · `icon-maskable.png` · `mark.png`

مهم: يكونوا في **الجذر** مباشرة، مش جوه فولدر باسم فيه مسافة.

**٢. آيفون:** افتح الرابط من **Safari** ← زرار المشاركة ← إضافة إلى الشاشة الرئيسية
**أندرويد:** من **Chrome** ← القايمة ⋮ ← تثبيت التطبيق

## اللغة
بيفتح أول مرة بلغة تليفونك. تقدر تغيّرها من **المزيد ← بياناتك ← اللغة**.

## التنبيهات
**الخطة ← نزّل ملف التقويم** ← افتح `sage.ics` على الموبايل ←
اعمل تقويم جديد اسمه Sage عشان تقدر تخفيه لوحده.

الموبايل نفسه هو اللي هينبّهك — تنبيهات نظام حقيقية شغّالة والتطبيق مقفول.
**كل ما تغيّر مواعيدك، نزّل الملف تاني.**

## نسخة احتياطية — مهم
البيانات كلها في متصفّح الجهاز ده بس. مسح بيانات المتصفّح أو تغيير التليفون بيمسح تقدّمك.
**المزيد ← بياناتك ← نزّل نسخة** كل فترة.

## اللي جوّه
- **النهاردة** — جدول بيتحسب حوالين مواعيدك الثابتة، وتحت كل بند «ليه؟» بالبحث والمرجع
- **الخطة** — مواعيدك، تنبيهات التقويم، معاينة الأسبوع
- **التمارين** — ٦ مقاييس: مدى الأرقام، قصر الذاكرة، المعايرة، الرجوع خطوة، ستروب، التمييز
- **القياس** — منحنياتك عبر الوقت
- **البطاقات** — مراجعة بالتباعد على بطاقاتك إنت
- **التوقعات** — تسجّل توقّع حقيقي باحتمال، وتحسمه في ميعاده، والتطبيق يقيس معايرتك
- **قصرك** — محطاتك الخاصة، وتمرين القصر بيستخدمها
- **المنهج** — ٩ وحدات بالبروتوكول والمصدر
- **الحدود** — اللي مالوش دليل، بصراحة
